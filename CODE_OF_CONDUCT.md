# Code of conduct

Be respectful, constructive, and welcoming to people of every background and
experience level. Critique the work, not the person. Respect privacy and give
credit for others' work.

Harassment, discrimination, threats, sexualized conduct, doxxing, and repeated
disruption are not acceptable in issues, pull requests, or project discussions.

Maintainers may edit or remove harmful content, close discussions, or restrict
participation. Responses should be proportionate and protect affected people.

Report problematic public content using GitHub's **Report content** tools or
contact the repository owner through an available private GitHub channel. Do not
publish private details to report misconduct. Maintainers are subject to these
same expectations.
